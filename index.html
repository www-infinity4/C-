Open C — Universal Scaffold Language

C•

A new software operating-system language built on the principle of the Universal Scaffold — a framework that mirrors biological substrates capable of holding energy, information, and nutrients simultaneously.

Quick Start Documentation

Core Philosophy

Just as plant pith is a lightweight, high-surface-area structure at the atomic level — a perfect "web" to catch and store energy — C• treats every data structure as a programmable scaffold: airy enough to be flexible, crystalline enough to hold a charge.

Language Highlights

  • CHON Primitives — carbon, hydrogen, oxygen, nitrogen are first-class scalar types.
  • Scaffold Structures — composite types that expose atomic-level surface area for binding.
  • Superior Pairings — a module system where two modules are explicitly paired to amplify one another's output.
  • Frequency Channels — messages are tagged with an electromagnetic frequency; the runtime routes them to the matching ion channel.
  • Betavoltaic Background — a built-in low-power runtime tick that never exhausts, modeled on ⁴⁰K radioactive decay.

Quick Start

Import the universal scaffold and the potassium pairing, then create a pith scaffold and pair it with potassium to make a nutrient battery: 

// Import the universal scaffold and the potassium pairing
use scaffold::Pith;
use pairings::PotassiumSalt;

// Create a pith scaffold and pair it with potassium to make a nutrient battery
let root: Pith<nitrogen> = Pith::new();
let battery = root.pair(PotassiumSalt);

// Feed a 40 Hz signal into the battery — matches banana-magnetism frequency
battery.emit(frequency: 40.hz, signal: "nutrient_pulse");

Research Foundations

  • Bio-Batteries — plant cellulose as a "paper" medium for holding electricity; the basis for the PotassiumSalt pairing and trickle mode.
  • Doped Semiconductors — adding a trace element to a crystal lattice makes it "special." Maps directly to coat_crystals() in the betavoltaic API.
  • Phloem Signaling — the plant's internal internet; the target for frequency-based programming via IonChannel and the FrequencyTable.
  • Betavoltaics — converting trace beta radiation from ⁴⁰K into a constant electrical trickle; the model for C•'s inexhaustible background runtime.
